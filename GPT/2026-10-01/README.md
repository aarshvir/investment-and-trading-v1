# GPT research workspace — 1 October 2026

Start with [the decision memo](INVESTMENT_DECISION_MEMO.md) or [the interactive decision dashboard](DECISION_DASHBOARD.html). The memo is authoritative for the recommendation; the dashboard is an explanatory view. [Release notes](RELEASE_NOTES.md) state the exact parents, changes and limits. This directory contains all newly authored research files for this turn. The required numbered release publisher also creates an immutable copy under `versions/` and updates shared navigation.

The package includes the user's [pasted audit](INPUT_CHATGPT_AUDIT.txt), source/price hashes, dated 90-name quote and prediction ledgers, 14 inherited scenarios repriced to September 30, v011 twenty-name shadow review, company/portfolio/method/decision challenges, scripts, tests and raw public captures. It does **not** claim fresh full-dossier underwriting of every stock or prove a forecasting edge. The frozen v011 and v012 parent archives remain separate and are identified in [PARENT_RELEASE_LINKS.json](PARENT_RELEASE_LINKS.json).

To reproduce the core public-price, scenario, allocation and ledger outputs from archived captures without network calls, run the `build_decision_inputs.py`, `build_portfolio_map.py`, `build_prediction_ledger.py`, `build_shadow_review.py` and `validate_release.py` files in that order. The method tests' archived Parquet checks require the Python 3.11 environment documented by the source-and-methods agent; a dependency-free fallback test is included there. No script accesses a brokerage account or places an order.
