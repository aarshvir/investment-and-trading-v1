# Shared research continuity

The user requires Claude and Codex to keep building on one another and retain all versions and reports.

Read `AGENTS.md`, `RESEARCH_VERSIONING.md`, `LATEST_HANDOFF.md` and `versions/catalog.json` before continuing. These are shared workspace instructions, not investment conclusions.

Preserve published releases, earlier audit reports, original inputs and other active workstreams. Claude's existing `v4/` remains its own working directory. Before producing a new deliverable, read the latest completed Codex and Claude releases, verify inherited claims, and record which findings were adopted, changed or rejected. Publish through the shared release tool with an explicit parent version and change log. Do not overwrite an older release or silently promote a draft to the current recommendation.

An external Claude chat does not automatically receive workspace files. When continuing outside this workspace, use the latest handoff and the referenced complete release package.
