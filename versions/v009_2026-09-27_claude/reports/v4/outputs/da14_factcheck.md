## 2. The FAIL, in full

### TJX — results table (§4): Q2 FY2027 net income mislabeled with the prior-year figure

**Dossier claim (TJX.md §4):** results table row "**Q2 FY27** (Aug '26 q, press release) | **1,243** (NI, XBRL) | +4% consolidated | $1.36 GAAP / $1.22 adj."

**Primary source (TJX Q2 FY2027 8-K Ex-99.1 Financial Summary, accession 0000109198-26-000045; confirmed in the Q2 FY2027 10-Q, accession 0000109198-26-000048):** the Financial Summary table reports, for the "Thirteen Weeks Ended August 1, 2026" (i.e., the actual Q2 FY2027 quarter), **Net income $1,520 million**. The figure **$1,243 million** appears in the same table's adjacent column, for the "Thirteen Weeks Ended August 2, 2025" — that is the **prior-year comparative quarter, Q2 FY2026**, not Q2 FY2027.

**Why it happened / why it matters:** TJX's fiscal year runs February–January, so "Q2" always refers to the 13 weeks ending in early August, and the current-year column sits to the *left* of the prior-year comparative column in TJX's own press-release tables — a layout mismatch is an easy trap when reading across fiscal-year labels quickly. The dossier's EPS figures ($1.36 GAAP / $1.22 adjusted), guidance table, capital-returns figures and balance-sheet figures are all independently verified correct and unaffected by this error — only the standalone net-income dollar figure in the §4 results table is wrong. It should read **$1,520mn**, not $1,243mn. This does not change the verdict or any kill criterion (none of TJX's five kill criteria reference net income directly), but it is exactly the kind of period-mislabeling risk the task instructions flagged for TJX and should be corrected before this cell is reused elsewhere (e.g., in a rolled-up net-income time series).
